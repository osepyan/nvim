## Treesitter
There are important requirements for properly treesitter v1.0 configuration.
Treesitter repo: https://github.com/nvim-treesitter/nvim-treesitter

### Requirements
- Neovim 0.12.0 or later (nightly)
- tar and curl in your path
- tree-sitter-cli (0.26.1 or later, installed via your package manager, not npm)
- a C compiler in your path (see https://docs.rs/cc/latest/cc/#compile-time-requirements)
